# 🦜这到底是个什么仓库？ | What exactly is this repository?
别期待什么厉害的开源大作。
这是一位来自18世纪的传奇航海长，专门堆放自学C写出来的所有东西：完整一点的小玩具、随手敲的练习demo、写一半就摆烂的试验代码，全都扔在这。
没有指针，没有结构体，没有算法黑魔法。
这个项目几乎把这位航海长现阶段全部掌握的语法用光了，属于学一点就硬凑出来的小故事程序。
代码写得很直白，甚至有点笨，但它是这位航海长敲出来第一个完整跑通的小项目。
Don't expect any impressive open‑source masterpiece.
This is a place where a legendary 18th‑century sailing master dumps everything they’ve written while teaching themself C: slightly more complete little toys, casual practice demos, and half‑finished experimental code they gave up on – all thrown in here.
No pointers, no structs, no algorithmic black magic.
This project almost exhausts all the syntax the navigator has mastered at this stage – it’s a little story program cobbled together with whatever they just learned.
The code is straightforward, even a bit clumsy, but it’s the first small project they ever wrote that actually runs from start to finish.
