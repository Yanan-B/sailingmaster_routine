# 🐛 错误记录
1.拼写错误：把 `sqrt` 拼成了 `sqart`，导致 LNK2019 链接错误。
2. 数位分离原理
   核心原理：C语言的整数除法‘/’和取余‘%’
   例子：378
   378 / 100 = 3
   378 / 10 = 37，37 % 10 = 7   (另一种写法是 j = (m % 100) / 10;，先用 378%100=78 去掉百位，再 78/10=7 去掉个位。)
   378 % 10 = 8
